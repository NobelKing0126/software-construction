# V1.0 项目初始化计划

**目标：** 建立可运行的纯 Java 控制台程序，实现管理员和学生登录及登录失败提示。

**实现方式：** 将固定账号、输入读取和凭据判断全部写在 `SystemMain.main` 中，按本阶段要求暂不分层、不抽取工具类。

**技术：** JDK 8 兼容 Java 语法、`Scanner`、控制台输入输出。

## 步骤与验收

1. 创建 `src/SystemMain.java`，以管理员账号 `admin/123456`、学生账号 `student/123456` 判断身份。
2. 编译：`javac -encoding UTF-8 -d out src/SystemMain.java`。预期成功且无编译错误。
3. 运行三次并分别输入管理员、学生、错误凭据；预期分别出现管理员欢迎提示、学生欢迎提示、登录失败提示。

## 范围核对

- 入口类名为 `SystemMain`，提供 `main` 方法。
- 交互从 `Scanner` 读取账号和密码。
- 三种验收结果均覆盖。
- 业务实现集中在主类中，符合 V1.0 的耦合约束。
