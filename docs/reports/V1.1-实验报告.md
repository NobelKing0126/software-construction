# V1.1 实验报告：用户注册功能

## 一、实验目标

在 V1.0 控制台程序上增加用户注册功能，使用 `HashMap<String, String>` 在内存中管理用户账号和密码；移除硬编码账号，并为账号、密码增加独立校验方法。

## 二、实验环境

- 操作系统：Windows（本机环境）
- JDK：Eclipse Temurin 8，版本 `1.8.0_504`
- 编译命令：`javac -encoding UTF-8 -d out src/SystemMain.java`
- 运行入口：`SystemMain`

## 三、设计与实现

程序启动后显示登录、注册和退出菜单。用户数据保存在本次程序运行期间的 `HashMap<String, String>` 中，程序退出后数据不保留。

注册时读取账号和密码，账号不能为空，密码不能为空且长度至少为 6 位，账号不能与已有账号重复。校验通过后将账号和密码存入集合。登录时通过集合查找账号并核对密码。登录、注册和账号密码校验分别由独立方法完成，主流程负责菜单交互。

## 四、测试输入与实际结果

使用 JDK 8 编译成功。按以下场景运行控制台程序，检查实际提示：

| 场景 | 输入 | 实际结果 |
|---|---|---|
| 注册有效账号 | 选择注册，账号 `bob`，密码 `123456` | 注册成功 |
| 注册重复账号 | 再次注册 `bob` | 提示账号已存在，注册失败 |
| 注册空账号 | 账号留空 | 提示账号不能为空 |
| 注册空密码 | 输入账号 `carol`，密码留空 | 提示密码不能为空且长度不能少于6位 |
| 注册短密码 | 输入账号 `dave`，密码 `12345` | 提示密码不能为空且长度不能少于6位 |
| 验证长度边界 | 密码输入 `123456` | 注册成功，长度 6 的密码符合要求 |
| 注册后登录 | 输入已注册的 `bob` 和密码 `123456` | 登录成功 |
| 验证旧固定账号已移除 | 登录账号 `admin`、密码 `123456` | 登录失败 |

上述注册、重复账号、输入校验和登录场景均通过。运行时用户数据仅保存在内存中，退出后不会保存。

## 五、问题与处理

V1.0 使用固定账号进行登录判断，无法新增用户。本版本移除了固定账号判断，并改用用户集合完成注册和登录。当前阶段没有实现文件持久化。
